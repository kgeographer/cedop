## Comparative Analysis
- Which places/societies/sites are environmentally similar?
- How unusual is a given place relative to peers?

## Temporal / Trajectory Analysis
- How did environmental context change over time?
- Did historical transitions coincide with environmental shifts?

## Constraint / Affordance Analysis
- What opportunities and constraints characterize this setting?
- What subsistence/settlement strategies are environmentally plausible?

## Divergence / Dependency Analysis
- How dependent is a place on upstream/nonlocal environmental inputs?
- Where do outcomes diverge from environmental expectation?
